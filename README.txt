台股短線觀察室 — 網頁版 2.2
================================

一、開始使用（Windows 10 / 11）
1. 將 ZIP 完整解壓縮到任意資料夾；不要在 ZIP 預覽視窗內執行。
2. 雙擊「啟動看盤.exe」，程式會自動用預設瀏覽器開啟看盤網頁。
3. 輸入股票代號、市場、成本等，點「查詢並分析」。
4. 使用期間保留啟動程式的小視窗；關閉該視窗或點「結束看盤」即停止本機服務。
5. 換電腦時複製整個資料夾。免安裝 Python、Node.js、ASP、IIS、Codex 或 API 金鑰。

啟動程式使用 Windows 10/11 通常內建的 .NET Framework 4.6+；若公司電腦禁止
自製程式執行，請由管理者確認。程式未做商業程式碼簽章，請保留原始交付包供核對。
請保留 EXE、HTML、CSS 與所有 JS 檔案在同一層，不要只複製 EXE。
視窗沒有自動打開瀏覽器時，按啟動視窗中的「開啟看盤網頁」。

二、這次改版
- 2.2：網頁主題改為明亮玫瑰紅，保留紅漲綠跌及原有行情分析功能。
- 盤中：顯示證交所基本市況報導的最新一般交易成交價與成交時間。
- 收盤／假日：使用最後完成的日 K 收盤；當日日線尚未公布時，採已確認
  13:30 成交的收盤行情。未確認收盤時明確標示「收盤待確認」。
- 標題、02 關鍵價位、03 操作計畫、損益都使用同一筆價格與 K 線重算。
- 近三個月圖表加入日 K、MA5、MA20 及成交量；紅色收高於開、綠色收低於開。
- 盤中最後一根 K 線為未完成，隨報價更新；滑鼠移至 K 線可看開高低收與量。
- 三情境的格式與規則不變，其數值使用同一套更新後分析結果。
- 新增近期資訊：最近五個有資料日的法人買賣超、近期／已公告除權息、相關新聞。

三、更新、交易日與價格品質
- 一般交易時段按台北時間 09:00–13:30、週末與證交所年度休市日曆判斷。
- 臨時停市、停牌、無成交或公告未更新時，以來源日期／時間與警告為準。
- 盤中有效成交距今超過兩分鐘，顯示「時間較早」，不保證逐筆同步券商。
- 絕不以委買／委賣價格代替實際成交，也不把昨日收盤標示為今日即時價。
- 預設每 30 秒盤中更新；取消勾選可停止。切到背景分頁會暫停。
- 修改輸入欄位會暫停自動更新，按「查詢並分析」後才套用新設定。
- 每次更新均重新查詢成交價；歷史日線快取 5 分鐘、近期資訊快取 10 分鐘。
- 休市日曆快取一天。所有快取只在目前網頁記憶體中，關閉頁面即清除。
- 若盤中報價不可用，明確退回歷史收盤參考；若整體日線查詢失敗，隱藏舊分析。
- 收盤日線可含盤後／零股等成交量，盤中量是來源一般交易累計張數換算股數，
  因此兩者可能不同。盤中量比尚未累積全天，不能直接視為全天強弱。
- 網頁要繼續使用，啟動程式必須保持運行。關閉瀏覽器並不會自動關閉啟動程式。

四、近期資訊的範圍
- 法人：查最近 21 個日曆日，顯示最多 5 個有資料的交易日；正數買超、負數賣超。
  外資含 Foreign_Investor / Foreign_Dealer_Self，投信為 Investment_Trust，
  自營商含 Dealer_self / Dealer_Hedging；缺漏欄位不當成零，單位為千股。
  法人資料為盤後公布，並非當下盤中即時買賣超。
- 除權息：查最近 400 天資料，列近 120 天及已公告未來除權息日，最多 8 筆。
  現金股利含盈餘與公積配發；股票股利顯示面額金額，不是持股增加百分比。
  未取得資料不代表沒有配息；未公告未來日期不會被預測出來。
- 新聞：由今天往回查最多 14 日，最多列 8 則；API 一次只支援一個日期。
  排除討論區與重複網址，依來源時間排列，保留媒體與原文連結。
  時間按供應商原欄位列示，來源未提供時區，不另推定。不是完整重大訊息清單，
  也沒有使用 AI 判斷重要性、真偽或投資影響。
- 各資料服務可能延遲、缺漏、限流或修改存取政策；失敗的區塊會明確提示。

五、資料與隱私
- 歷史日線：FinMind TaiwanStockPrice；上市可備援至臺灣證券交易所 STOCK_DAY。
- 一般交易行情：證交所基本市況報導（包含上市／上櫃）。
- 休市日曆：臺灣證券交易所。法人、股利、新聞：FinMind。
- 市場別需自行正確選擇，完整代號 .TW / .TWO 可覆蓋市場選項。
- 成本與 NAV 在瀏覽器內計算，不送給行情服務。不儲存帳號、金鑰或持股資訊。
- 啟動程式僅監聽 127.0.0.1 的隨機連接埠，非對外網站，也不安裝系統服務。
  即時行情轉接只接受固定來源與有效股票代號，沒有任意網址代理功能。
- 不依賴外部 JavaScript CDN；下載 JSON 包含成本／NAV、行情、分析及近期資訊，
  請自行保管。

六、分析限制
- 延續既有 SMA5/10/20、RSI14、ATR14、量比、近 20 日支撐壓力與價位公式。
- 至少需要 20 個交易日，最多使用 90 日計算；圖表顯示最近價格日期起往前三個月。
- RSI 單邊上漲／下跌／完全持平分別處理為 100／0／50。
- 缺漏行情不補造，成本／NAV 必須正值，ATR 為零時不產生價位。
- 原始價格未做除權息、分割或合併還原。重大公司行動可能造成指標失真。
- 價格四捨五入至二位小數，尚未依台股各價格級距跳動單位修整。
- 觀察週期固定 1–5 個交易日；不預測每日價格、不保證報酬。
- 持有損益為價差，未含費稅與配息。ETF NAV 由使用者提供，須自行確認日期。
- 第二賣點僅在突破第一壓力且回踩不破的條件下啟用。
- 仍未涵蓋 Skill 全文所有判讀條件。盤中交易請核對券商行情。

七、直接開啟 HTML / 其他作業系統
未設定行情 API 時，可直接開 index.html 查看歷史日線與近期資訊，盤中報價會提示未設定。
完整版的 EXE 是 Windows 程式，不能在 macOS / 手機執行。
線上版可使用 GitHub Pages 搭配 Cloudflare Workers 行情 API；依部署說明建立 Worker，
再把它的 HTTPS 根網址填入 config.js 的 quoteApiBase，並上傳所有網頁檔案。
預設 API 只允許 https://justin1980go.github.io 網站跨站讀取；直接開檔案或其他網域
需要相應調整 API 存取設定。使用 Windows 啟動程式時，優先使用本機行情服務。
部署程式已提供，但仍需在使用者帳號部署並驗證雲端能取得行情；健康檢查通過不代表
行情來源可用。API 遇到來源限制會顯示錯誤，不補造價格。

八、版本驗證
