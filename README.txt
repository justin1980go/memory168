台股短線觀察室 — 可攜網頁版 1.0
================================

一、開始使用
1. 將 ZIP 完整解壓縮到任意資料夾；不要直接在 ZIP 預覽視窗執行。
2. 用最新版 Microsoft Edge、Chrome 或 Firefox 開啟 index.html。
3. 確認網路連線，輸入代號、市場與資產類型，點「查詢並分析」。
4. 換電腦時複製整個資料夾即可。無需 Python、Node.js、ASP、IIS、Codex 或 API 金鑰。

請保留 index.html、style.css、engine.js、data.js、app.js 在同一資料夾。
所有畫面與計算程式均在資料夾中，不依賴 CDN 或外部 JavaScript 套件。
本版沒有伺服器、安裝程序、背景服務、帳號或資料庫。

二、資料與隱私
- 預設 FinMind 的 TaiwanStockPrice 日成交資料，可查上市、上櫃與 ETF。
- 自動模式下，上市若 FinMind 連線失敗，改查臺灣證券交易所的六個月份資料。
- 上櫃請使用 FinMind。證交所來源只支援上市，不適用上櫃。
- 市場選擇供報告代號與備援路由使用；FinMind 以代號查詢，本版不另行驗證上市櫃分類。
- 不直接使用 Yahoo：本版驗證時 Yahoo 未允許本機網頁跨站讀取。
- 瀏覽器只向行情服務傳送查詢代號與日期；成本、NAV 只在本機計算。
- 畫面、成本與 NAV 不存入 localStorage。頁面記憶體暫存行情 5 分鐘，關閉頁面即清除。
- 下載的 JSON 包含成本、NAV（若有）、分析與日線資料，請自行保管。
- 最新日資料可能延遲，這是日線／盤後分析，不是即時報價。
- 網路來源有流量與可用性限制；若其跨站政策改變，需更新 data.js 或改採伺服器架構。
- 無資料、資料不足、缺漏 OHLCV 或連線失敗時不輸出新分析，也不沿用前一檔結果。

三、分析規則與限制
- 保留原 Python 版的 SMA5/10/20、RSI14、ATR14、量比、20 日支撐壓力與價位公式。
- 最多使用最近 90 個有效交易日，走勢圖顯示最近 60 日；至少需要 20 日。
- JavaScript 版對 RSI 單邊上漲／下跌／完全持平補齊 100／0／50 邊界值。
- 拒絕零或負數成本、NAV；缺漏行情不補造；ATR 為零時不產生價位。
- 正值價格底線為 0.01，分析價位四捨五入至小數二位，尚未依台股跳動單位修整。
- 未還原除權息、分割或合併價格，重大公司行動需人工核對。
- 固定以 1–5 個交易日觀察，不依持有天數調整或預測每日價格。
- 若有成本，顯示持有與出場計畫；損益僅為價差，未計交易成本與配息。
- ETF NAV 須自行確認與行情同一天，折溢價不是即時 iNAV。
- 第二賣點僅在突破第一壓力且回踩不破的條件下啟用。
- 本版延續現有程式規則，尚未實作 Skill 全文中的所有判讀條件。
- 分析不保證報酬；盤中請核對券商即時行情。

四、輸出與列印
查詢完成後可下載 JSON，或按「列印／另存 PDF」使用瀏覽器列印功能。
本版不提供離線查價或歷史檔案匯入。

五、常見問題
畫面沒有樣式：請確認整個資料夾已解壓縮，其他四個檔案與 index.html 同層。
一直查不到：核對代號與網路，可切換行情來源。上櫃不要選證交所。
出現跨站讀取錯誤：更新瀏覽器、確認公司網路政策；不要停用瀏覽器安全機制。
不是今天的資料：可能休市、停牌或供應商尚未更新；請以畫面所列行情日期為準。
需要網址分享：本資料夾可作為後續靜態網站內容；本次沒有部署或公開發布。
